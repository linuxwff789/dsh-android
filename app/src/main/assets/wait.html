等待 Termux DSH 服务

这个 APK 是 WebView 客户端，Debian、Node.js 和 DSH 都由 Termux 安装。

安装时请看 Termux 终端窗口
安装命令行输出不会显示在 APK 内，因为 Android 应用不能读取 Termux 的私有终端输出。

请在 Termux 中执行：

bash ~/dsh-android/scripts/termux-setup-dsh.sh

脚本会显示 apt 下载、Node.js 安装、pnpm install、node-pty 编译和 DSH build 的实时输出。完成后本页会自动连接。
